# Results

This directory is intentionally empty in the source release.

The analysis scripts generate the full result tables, checkpoints, reconstructed feature caches, and figures locally. Large generated arrays and model checkpoints are excluded from Git through `.gitignore`.

For a compact archival release, the most useful manuscript-facing outputs to copy here after a successful run are:

- `experiment2_results.csv`
- `experiment2_plus_t12.csv`
- `frozen_measured40_primary_transfer.csv`
- `frozen_measured40_all_models_summary.csv`
- `model_class_transfer_degradation_summary.csv`
- `transfer_delta_R2_by_model_and_reconstruction.csv`
- the model-class transfer figures generated by script 05

Do not commit the HSIwheat cubes, large `.npy`/`.npz` caches, or `.pth` checkpoints unless there is a specific archival reason to do so.
